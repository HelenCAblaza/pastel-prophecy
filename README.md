# The Pastel Prophecy

A mobile-first soft watercolor oracle app.

## V1 features

- 78 original tarot-inspired oracle cards
- Heart / Path / Magic three-card spread
- Magical shuffle animation before picking
- Mobile-friendly 24-card selection grid
- Animated card containers with glow, shimmer, sparkles, and float effects
- Short explanation for each card
- Combined prophecy summary
- Download reading as a PNG image via html2canvas

## Local preview

```bash
python3 -m http.server 8000
```

Open: <http://localhost:8000>

## Deploy

This static app can be deployed directly with GitHub Pages from the `main` branch root.
