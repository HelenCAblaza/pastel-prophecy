# Pastel Prophecy — 78 Card Original Art Prompt Pack

Use this for consistent image generation in a whimsical watercolor-kawaii style.

## Global style lock
- Vertical tarot card composition (2:3)
- Watercolor texture on paper
- Palette: lavender, blush pink, mint, baby blue, moon cream, soft gold accents
- Delicate fairy-gold frame + tiny stars
- Rounded kawaii forms, soft linework (no harsh black)
- Magical sparkles, gentle mist, dreamy lighting

## Negative prompt (apply to all cards)
- horror, gore, photorealism, gritty texture, neon oversaturation
- harsh black outlines, muddy browns, cluttered composition
- text blocks or watermarks

## Master prompt suffix (append to each card prompt)
"whimsical pastel watercolor tarot illustration, ornate delicate gold filigree border, dreamy moonlit atmosphere, fluffy clouds, floating sparkles, soft painterly brushwork, high detail but gentle contrast, cohesive deck style, vertical card"
